## 🚀 About Me

I'm **Argha Kundu**, a Software Engineer and Backend Developer focused on building **reliable APIs, modern web applications, and AI-powered systems**.

I primarily work with the **JavaScript/TypeScript ecosystem**, using Node.js and Express for backend development and React for frontend applications. I'm also expanding into **AI/LLM engineering**, learning how to integrate modern AI capabilities into real-world software.

* 💻 **Backend:** Node.js, Express.js, REST APIs, authentication & backend architecture
* 🎨 **Frontend:** React, TypeScript, JavaScript, HTML & CSS
* 🗄️ **Databases:** MongoDB, PostgreSQL, Prisma & Mongoose
* 🤖 **AI:** Generative AI, LLM APIs, RAG & AI Agents
* 🧠 **Problem Solving:** 300+ LeetCode problems
* 🎓 **Education:** M.Tech in ECE (AI), IIIT Guwahati
* 🏆 **Achievement:** TCS CodeVita 2025 — Global Rank 3929
* 🚀 **Currently:** Building projects and improving my backend + AI engineering skills
