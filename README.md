### 👨‍‍💻 Engineering Profile

I am a Software Engineer focused on high-throughput **Backend Systems**, **Database Architecture**, and **Applied AI Engineering**. I specialize in creating reliable APIs, concurrent job processors, and agentic workflows using modern TypeScript and Node.js.

- ⚙️ **Core Backend:** Node.js, Express.js, RESTful Architecture, JWT Auth, Microservice design.
- 🗄️ **Databases & ORMs:** PostgreSQL, MongoDB, Prisma, Mongoose, transaction management & indexing.
- 🤖 **AI & LLM Systems:** LangChain, RAG Pipelines, Tool Calling, Vector Stores, OpenAI & Gemini APIs.
- 🎓 **Academics:** M.Tech in ECE (Specialization in AI), **IIIT Guwahati**.
- 💡 **Philosophy:** *"Design clean schemas, profile before optimizing, build systems that fail gracefully."*
